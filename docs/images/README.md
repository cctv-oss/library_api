# 项目截图存放目录

把下面 5 张截图放到这个目录（`docs/images/`），文件名保持对应，README 里的图片就会自动显示。

| 文件名 | 截图内容 | 怎么截 |
|--------|---------|--------|
| `login.png` | 登录页 | 打开 http://localhost:5173，看到登录页截图 |
| `books.png` | 图书管理 | 管理员登录后，点左侧「图书管理」 |
| `readers.png` | 读者管理 | 点左侧「读者管理」 |
| `borrows.png` | 借阅管理 | 点左侧「借阅管理」 |
| `reader-books.png` | 读者端图书查询 | 用读者账号登录，点「图书查询」 |

截图建议：窗口缩到普通大小，保证表格内容完整可见即可。
